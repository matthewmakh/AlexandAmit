# Farkas Capital platform

White-label capital raising: invest on the company's own website, keep each investment as a branded Apple Wallet or Google Wallet pass, run the raise from an issuer dashboard, and keep compliance with the broker-dealer in an operations console.

Built by TyeNY LLC for Farkas Capital under SOW FC-2026-01. Start with [`CLAUDE.md`](CLAUDE.md) and [`docs/`](docs/README.md).

The clickable demo that won the work lives on the `claude/gallant-volta-q3lkph` branch. It is a design reference only.
